# My Hero Academia-Inspired Motion & UI Specimen Catalogue

A catalogue of portable web motion/UI artifacts inspired by the visual
grammar of **My Hero Academia**: comic-book impact, hero analysis, Quirk
activation, training telemetry, emergency alerts, tournament
presentation, agency dashboards, support-tech interfaces, and explosive
character-introduction energy.

> **Design rule:** extract interaction principles and visual grammar
> rather than reproducing copyrighted frames, logos, character art,
> exact costumes, or proprietary title cards.
>
> These concepts are intended for `playground.humza-butt.space`:
> self-contained HTML/CSS(+tiny JS) specimens that work inside a
> sandboxed iframe and can be transplanted into unrelated software.

# 53. Playground Implementation Contract

For every specimen chosen from this catalogue:

-   Prefer plain HTML + CSS.
-   Use tiny deterministic JavaScript only where pointer tracking,
    drag/drop, measurement, timers or interaction state genuinely
    require it.
-   Assume `<iframe sandbox="allow-scripts">`.
-   Never require parent-window access, same-origin privileges, storage,
    network calls, React/Vue, or native device APIs.
-   Prefer `deps: none`.
-   Freeze exact colours, durations, geometry and thresholds in the
    specimen.
-   Do not use runtime randomness.
-   Add a scaffold whenever the effect requires a host card, dashboard,
    map, roster, tournament bracket, etc.
-   Looping effects must stop under `prefers-reduced-motion` and
    `data-force-reduced-motion`.
-   Prefer finite animation sequences over perpetual particles.
-   Under reduced motion, preserve semantic hierarchy and state with
    static impact geometry, halftone, borders, typography, or colour.
-   Use original icons, silhouettes, copy, logos and shapes.
-   Do not copy anime frames, manga panels, character likenesses, U.A.
    insignia, hero costumes, title logos, or exact proprietary
    typography.
-   The specimen should express the **motion principle**, not function
    as a miniature reproduction of the show.
-   Acceptance criteria must describe observable behaviour.
-   Reset/replay must be deterministic.
-   Register specimens explicitly in `src/specimens/index.ts`.

# Catalogue Thesis

My Hero Academia is unusually fertile inspiration for software motion
because its visual language is already built around **capability,
analysis, escalation, impact, competition, status and transformation**.

Those concepts translate directly into interface semantics:

-   **Quirks** → capabilities and feature state
-   **Power percentage** → resource usage and thresholds
-   **Hero analysis** → diagnostics and AI insight
-   **Training** → testing and evaluation
-   **Rankings** → leaderboards and comparative metrics
-   **Agencies** → assignment and workflow
-   **Emergency alerts** → incidents and security
-   **Support equipment** → plugins, integrations and tooling
-   **Licenses** → credentials and permissions
-   **Tournament brackets** → experiments and comparisons
-   **Team-ups** → collaborative workflows
-   **Manga impact language** → high-priority feedback

The strongest specimens should therefore feel energetic without becoming
mere decoration. Every burst, line, panel, fracture or slam should
explain **what just changed in the software**.
