# Manga-Inspired Motion & UI Specimen Catalogue

A catalogue of **270 portable specimen concepts across 35 families**,
inspired by manga's visual grammar rather than any particular series or
artist.

> Use original panels, lettering, avatars, ink marks and geometry. Do
> not reproduce published manga panels, identifiable characters, logos,
> dialogue, proprietary fonts or signature compositions.

# Strong Software Mappings

-   **Panels → dashboards:** unequal panel sizes make priority spatial.
-   **Panel expansion → drill-down:** detail views grow directly from
    their source card.
-   **Gutters → navigation:** borders become wipes, shutters and
    transition masks.
-   **Speed lines → urgency:** direction and acceleration become visible
    without relying on colour.
-   **Impact frames → confirmation:** one finite contrast beat makes
    consequential actions unmistakable.
-   **Speech balloons → contextual help:** guidance stays attached to
    the control it explains.
-   **Screentone → state density:** dot density can represent progress,
    severity, confidence or activity.
-   **Ink circles → focus:** selection feels hand-marked instead of
    chrome-highlighted.
-   **Reaction panels → notifications:** secondary events interrupt
    without replacing the main context.
-   **Double-page spreads → milestones:** major completion states
    temporarily escape normal layout constraints.
-   **Training montages → multi-stage progress:** long processes
    compress into memorable milestones.
-   **Deduction chains → reasoning workflows:** evidence or inputs
    visibly collapse into a decision.
-   **Rival splits → comparison:** two products, versions or metrics
    confront one another spatially.
-   **Evidence boards → dependency graphs:** ink connections make
    relationships tangible.

# Playground Technical Contract

-   Plain HTML + CSS preferred; tiny deterministic vanilla JS where
    necessary.
-   Must run in `<iframe sandbox="allow-scripts">`; no same-origin,
    parent APIs, storage, fetch or navigation.
-   No frameworks, external images, manga scans, fonts, audio or video.
-   Original inline SVG/CSS is ideal for speed lines, screentone,
    balloons, brush strokes and splatters.
-   Prefer `deps: ['none']` and deterministic pre-authored geometry
    instead of runtime randomness.
-   Freeze panel dimensions, gutter widths, angles, dot spacing,
    timings, easing and copy.
-   Honour `prefers-reduced-motion` and `data-force-reduced-motion`;
    preserve a clear static composition.
-   Avoid repeated high-contrast flashing. Impact frames must be finite.
-   Preserve DOM reading order even when visual panels are irregular.
-   Register explicitly in `src/specimens/index.ts`; do not redesign
    catalogue chrome.

# Catalogue Thesis

Manga is unusually fertile UI material because its core tools already
solve interface problems: **panels are containers, gutters are pacing,
balloons are contextual overlays, screentone is state texture, speed
lines are directional feedback, reaction panels are notifications, page
turns are navigation, and impact frames are confirmation.**

The strongest specimens should make software feel **composed, paced and
dramatically hierarchical** without requiring copyrighted characters or
artwork.
