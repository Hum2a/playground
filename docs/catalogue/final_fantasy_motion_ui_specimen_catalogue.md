# Final Fantasy-Inspired Motion & UI Specimen Catalogue

A catalogue of **208 portable motion/UI concepts across 26 families**,
inspired by JRPG battle HUDs, command menus, gauges, materia-like
sockets, magic casting, summon reveals, victory results, progression,
world maps, crystals, quests and cinematic transitions.

> **Creative rule:** study recurring JRPG interaction patterns rather
> than copying any particular game assets. Use original typography,
> fictional labels, abstract placeholders and newly designed geometry.
> Do not reproduce franchise logos, character art, exact HUDs,
> copyrighted spell names, proprietary icons, music or extracted game
> assets.

# Suggested Original Visual Grammar

Use a restrained fantasy-JRPG palette rather than reproducing a specific
game:

-   deep navy `#111827`
-   midnight `#172033`
-   parchment `#E9E3D2`
-   silver `#C7CDD8`
-   crystal cyan `#72D6E8`
-   magic violet `#A98BFF`
-   warm gold `#E5BE62`
-   danger crimson `#C94F58`

Colour communicates state: readiness, reward, magic, danger or
selection. Avoid making every specimen rainbow fantasy UI.

Useful frozen constants: - command-panel border: `2px` - crystal facet
stroke: `2px` - gauge height: `8–14px` - command entrance: `220–420ms` -
result tally interval: `70ms` per row - impact frame: `60–100ms`
maximum - target reticle settle: `260ms` - particle counts must be
fixed, not random

# Playground Technical Contract

-   Prefer plain HTML + CSS; tiny deterministic vanilla JS only where
    counters, gauges, selection or sequencing require it.
-   Must run inside `<iframe sandbox="allow-scripts">`.
-   Never require `allow-same-origin`, parent access, storage, fetch,
    navigation, WebAudio, WebMIDI or external APIs.
-   No React/Vue/framework runtime inside specimens.
-   No external game assets, extracted textures, audio, fonts or logos.
-   Use original inline SVG/CSS for crystals, magic circles, gauges,
    reticles and particles.
-   Prefer `deps: ['none']`.
-   Freeze exact durations, counts, colours, gauge ranges, particle
    positions and geometry.
-   Avoid runtime randomness.
-   Honour both `prefers-reduced-motion` and
    `data-force-reduced-motion`.
-   Looping gauges/pulses become static representative states under
    reduced motion.
-   High-contrast flashes must be finite and must not rapidly repeat.
-   Replay/reset must clear timers and transient state.
-   Preserve keyboard accessibility for commands, targets and choices.
-   Register explicitly in `src/specimens/index.ts`.
-   Do not redesign catalogue chrome.
-   Acceptance criteria must be observable and numerical where
    practical.

# Catalogue Thesis

Final Fantasy-style interfaces turn invisible state into **ritual**. A
command becomes a physical menu. Readiness becomes a filling gauge. A
new ability becomes a reveal. A reward becomes a tally. A target becomes
a reticle. A checkpoint becomes a crystal. A major state change gets
cinematic framing.

For the Playground, the strongest specimens should borrow that grammar
without becoming cosplay. The goal is to make software states feel
**earned, charged, staged and legible**: the UI should tell the user not
only what happened, but that something meaningful just happened.
