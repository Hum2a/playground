# Recents Card Restore (portable recreation spec)

Overview with three 286×500 task cards. Selecting any card expands it to
390×700 over 380ms. OVERVIEW reconstructs the task arrangement.

## Contract

| Parameter | Value |
| --------- | ----- |
| Cards | 286×500px |
| Viewport | 390×700px |
| Transition | 380ms |
| Radius | 26px → 0 |

## API

- `resetRecentsCardRestore()`

## Porting

Import `demo.css` verbatim.
