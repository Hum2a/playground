# Quick Settings Expansion (portable recreation spec)

360×96 compact strip transforms into 360×330 panel with 2×3 tile grid.

## Contract

| Parameter | Value |
| --------- | ----- |
| Compact | `360 × 96px` |
| Expanded | `360 × 330px` |
| Duration | `360ms` |
| Extra controls | fade after ~45% (`162ms`) |

## Reduced motion

Immediate geometry switch.

## API

- `resetQuickSettingsExpansion()`
