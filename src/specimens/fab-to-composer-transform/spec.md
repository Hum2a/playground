# FAB-to-Composer Transform (portable recreation spec)

FAB container morph: 56×56 button grows into 342×210 composer anchored 24px from edges.

## Layout contract

| Token | Value |
| ----- | ----- |
| Scaffold | 390 × 640px |
| FAB | 56 × 56px |
| Composer | 342 × 210px |
| Radius | 28 → 24px |
| Duration | 360ms |

## API

- `resetFabToComposer()`
- `replayFabToComposer()`
