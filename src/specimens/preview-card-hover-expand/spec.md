# Preview Card Hover Expand

Focused content expands while adjacent cards move outward rather than overlap.

## Freeze

| Item | Value |
| --- | --- |
| Cards | 3 |
| Expand scale | 1.18 |
| Neighbour push | ~22px |
| Duration | 220ms |

## API

- `runPreviewExpand(index?)`
- `runPreviewCollapse()`
