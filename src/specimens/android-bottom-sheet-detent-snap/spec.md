# Bottom Sheet Detent Snap (portable recreation spec)

390×700 host with draggable bottom sheet. Detents: collapsed 96px, medium
360px, expanded 640px. Scrim maps 0→0.34. Velocity bias at 0.55 px/ms.

## API

- `applyResistance(rawH)`
- `resetBottomSheetDetentSnap()`

## Porting

Import `demo.css` verbatim.
