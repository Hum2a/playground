# Permission Prompt Materialise (portable recreation spec)

Centred 320×250 decision surface over 0.28 scrim. Visual simulation only.

## Contract

| Parameter | Value |
| --------- | ----- |
| Dialog | `320 × 250px` |
| Scrim | opacity `0.28` |
| Materialise | scale `0.94→1` over `220ms` |
| Actions | While using, Only this time, Don't allow |

## Reduced motion

Prompt appears immediately.

## API

- `resetPermissionPromptMaterialise()`
