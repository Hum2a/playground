# Extended FAB Collapse (portable recreation spec)

152×56 extended FAB contracts to 56×56 icon-only on downward scroll accumulation.

## Contract

| Parameter | Value |
| --------- | ----- |
| Extended | `152 × 56px` |
| Collapsed | `56 × 56px` |
| Collapse threshold | `48px` down accumulation |
| Expand threshold | `36px` up accumulation |
| Duration | `240ms` |

## Reduced motion

Immediate width state switch.

## API

- `resetExtendedFabCollapse()`
