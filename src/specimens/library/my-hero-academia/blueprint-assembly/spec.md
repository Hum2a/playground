# Blueprint Assembly

## Visual intent

Four labeled blueprint parts at corners converge into a finished CAPTURE RIG device on a grid stage.

## Timing

| Phase | Start | Effect |
| --- | --- | --- |
| Assemble | 0ms | Parts converge (660ms) |
| Device | 560ms | CAPTURE RIG reveals |
| Settled | 1310ms | Final device state |
