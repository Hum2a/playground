# Skill Inheritance Select

Select capability chips from MODEL A / MODEL B; each chip travels into RESULT.

## Sequence

1. Click HEAL-01 or SHOCK-02
2. Chip marks sent; slot enters RESULT with 320ms travel
3. Reset clears RESULT and restores chips

## Reduced motion

Slots appear immediately with no travel animation.

## Palette

`#F5C400` / `#101010` / `#F7F3E8` / `#E8E8E8`
