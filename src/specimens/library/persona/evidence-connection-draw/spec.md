# Evidence Connection Draw (portable recreation spec)

Two clue cards; click each to draw a connecting line and show linked relationship.

## Interaction

1. Click first clue — selected state
2. Click second clue — line draws between centers (480ms)
3. Reset clears selection and line

## Reduced motion

Line appears immediately without stroke-dash animation.

## Palette

`#F5C400` / `#101010` / `#F7F3E8` / `#E8E8E8`
