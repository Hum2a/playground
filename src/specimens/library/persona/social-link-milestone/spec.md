# Social Link Milestone (SPX-2971)

Bond nodes converge onto a profile card and unlock a capability badge.

## Sequence

1. Converge — nodes travel toward the card (720ms)
2. Unlock — UNLOCKED badge scales in (400ms)
3. Done — badge and clustered nodes remain

## Copy

Profile label is abstract (`BOND // 02`). No character names.

## Reduced motion

Nodes rest near the card; unlock badge visible immediately.
