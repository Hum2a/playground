# Fusion Preview

Select MODEL A and MODEL B, then run a finite beam that settles into a SIGMA ghost preview.

## Sequence

1. Select both inputs
2. Beam — gold rays converge (480ms, B staggered +120ms)
3. Settle — SIGMA preview holds (420ms)
4. Done — preview stays until reset

## Reduced motion

SIGMA preview appears immediately on run.
