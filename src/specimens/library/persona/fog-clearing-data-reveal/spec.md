# Fog-Clearing Data Reveal (portable recreation spec)

Fog overlay obscures case data until a clear process completes.

## Interaction

- Clear fog button runs ~1400ms progressive reveal
- Progress bar tracks completion
- Reset restores fog state

## Reduced motion

Fog removed immediately; data fully visible.

## Palette

`#F5C400` / `#101010` / `#F7F3E8` / `#E8E8E8`
