# Static Portal Materialise

Persona 4–adjacent TV-world portal: analogue static condenses and resolves into a clean interactive panel.

## Visual intent

- Full-stage static noise field on ink background
- Panel materialises from centre with yellow accent label
- Palette: `#F5C400`, `#101010`, `#F7F3E8`, `#E8E8E8`

## Interaction

- Materialise button runs condense sequence (~760ms)
- Reduced motion: panel appears instantly, static hidden

## Reduced motion

Disable noise flicker and condense animations under both RM triggers.

## Accessibility

- Live region announces idle → condensing → ready states
- Panel action button has `:focus-visible` ring
