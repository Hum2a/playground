# TV Screen Dive Transition (portable recreation spec)

Real-world UI scales into a yellow aperture; TV-world layer emerges from depth.

## Sequence

1. Idle — investigation UI visible
2. Dive — layer scales down with perspective (680ms)
3. Emerge — destination scales from 1.4 to 1 (520ms)
4. Done — TV world visible

## Reduced motion

Destination layer shown immediately without dive animation.
