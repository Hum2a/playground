# Arcana Card Draw (SPX-2980)

Card rises from a deck, flips, and reveals an abstract category result.

## Sequence

1. Rise — card lifts from deck (480ms)
2. Flip — rotateY to face (520ms)
3. Done — CATEGORY / VII visible

## Copy

Abstract labels only (`CATEGORY` / `VII`). No tarot IP names.

## Reduced motion

Card appears face-up immediately.

## Palette
