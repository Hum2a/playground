# Tube Warm-Up

A portable, manufacturer-neutral tube heater warm-up panel with fixed values and three explicit states: idle, action, and final. It uses no audio, network access, storage, or randomness.

## Interaction
Press **WARM** to show the fixed action state, then the completed `HEATER 100% · READY` result. **RESET** returns the panel to `HEATER 0%`.

## Reduced motion
Either reduced-motion trigger renders the final state immediately, with the completed result kept in the visible readout and live status text.
