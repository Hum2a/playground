# Rack Unit Power-On

A portable, manufacturer-neutral rack power sequence panel with fixed values and three explicit states: idle, action, and final. It uses no audio, network access, storage, or randomness.

## Interaction
Press **POWER** to show the fixed action state, then the completed `RAIL +24.0 V · ONLINE` result. **RESET** returns the panel to `RAIL 0.0 V`.

## Reduced motion
Either reduced-motion trigger renders the final state immediately, with the completed result kept in the visible readout and live status text.
