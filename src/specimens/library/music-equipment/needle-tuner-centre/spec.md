# Needle Tuner Centre

A portable, manufacturer-neutral needle centring panel with fixed values and three explicit states: idle, action, and final. It uses no audio, network access, storage, or randomness.

## Interaction
Press **CENTRE** to show the fixed action state, then the completed `E2 · 0 cents · IN TUNE` result. **RESET** returns the panel to `E2 · -18 cents`.

## Reduced motion
Either reduced-motion trigger renders the final state immediately, with the completed result kept in the visible readout and live status text.
