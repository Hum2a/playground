# Strobe Tuner Lock

A portable, manufacturer-neutral strobe pitch lock panel with fixed values and three explicit states: idle, action, and final. It uses no audio, network access, storage, or randomness.

## Interaction
Press **LOCK** to show the fixed action state, then the completed `A440 · 0 cents · LOCKED` result. **RESET** returns the panel to `A440 · -12 cents`.

## Reduced motion
Either reduced-motion trigger renders the final state immediately, with the completed result kept in the visible readout and live status text.
