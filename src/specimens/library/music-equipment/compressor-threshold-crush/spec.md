# Compressor Threshold Crush

A portable, manufacturer-neutral compressor transfer curve panel with fixed values and three explicit states: idle, action, and final. It uses no audio, network access, storage, or randomness.

## Interaction
Press **CRUSH** to show the fixed action state, then the completed `OUTPUT CEILING -8 dB` result. **RESET** returns the panel to `THRESHOLD -8 dB`.

## Reduced motion
Either reduced-motion trigger renders the final state immediately, with the completed result kept in the visible readout and live status text.
