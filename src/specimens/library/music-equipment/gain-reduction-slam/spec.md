# Gain Reduction Slam

A portable, manufacturer-neutral gain reduction clamp panel with fixed values and three explicit states: idle, action, and final. It uses no audio, network access, storage, or randomness.

## Interaction
Press **SLAM** to show the fixed action state, then the completed `GR -12.0 dB · HOLD` result. **RESET** returns the panel to `GR 0.0 dB`.

## Reduced motion
Either reduced-motion trigger renders the final state immediately, with the completed result kept in the visible readout and live status text.
