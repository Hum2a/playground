# Auto Gain Scan

A portable, manufacturer-neutral automatic gain scan panel with fixed values and three explicit states: idle, action, and final. It uses no audio, network access, storage, or randomness.

## Interaction
Press **SCAN** to show the fixed action state, then the completed `TRIM +4.0 dB · -14.0 dBFS` result. **RESET** returns the panel to `INPUT -18.0 dBFS`.

## Reduced motion
Either reduced-motion trigger renders the final state immediately, with the completed result kept in the visible readout and live status text.
