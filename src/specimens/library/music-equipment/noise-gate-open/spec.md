# Noise Gate Open

A portable, manufacturer-neutral noise-gate threshold open panel with fixed values and three explicit states: idle, action, and final. It uses no audio, network access, storage, or randomness.

## Interaction
Press **OPEN** to show the fixed action state, then the completed `GATE OPEN · -34 dB` result. **RESET** returns the panel to `INPUT -62 dB`.

## Reduced motion
Either reduced-motion trigger renders the final state immediately, with the completed result kept in the visible readout and live status text.
