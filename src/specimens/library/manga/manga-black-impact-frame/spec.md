# Black Impact Frame

Finite manga-inspired impact emphasis for consequential software confirms. **Never loops. Never idle.**

## Behaviour

1. Anticipation — hold normal rendering for **60ms**.
2. Black impact — plate fills `#111111` for exactly **72ms** with a white silhouette outline of the focal card.
3. Inverse beat — optional **44ms** inverse-white plate with black silhouette.
4. Recovery — return to completed normal UI over **120ms**.
5. Done — confirmed badge; card content otherwise unchanged.

Reduced motion: no full-surface flash; completed card gets a static **6px** black border.

## Freeze

- Total ≤ **296ms** · black `#111111` · white `#F7F5EF`
- Zero looping · zero runtime randomness · busy lock blocks re-entry mid-sequence
