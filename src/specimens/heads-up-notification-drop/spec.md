# Heads-Up Notification Drop (portable recreation spec)

350×88px transient alert overlays host app. Entry 320ms, dwell 3200ms, exit
220ms. Click expands to 156px; swipe up >55px dismisses early.

## API

- `showHeadsUpNotification()`
- `resetHeadsUpNotificationDrop()`

## Porting

Import `demo.css` verbatim.
