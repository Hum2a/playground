# Weakness Highlight Sweep (portable recreation spec)

Analysis sweep highlights a critical weakness sector on a profile diagram.

## Palette

`#38A3FF` · `#101820` · `#F4F7FA` · `#FF4D35`

## Weak sector

`GUARD` bar at ~28% — lowest metric, accent highlighted.

## Timing

Sweep `500ms`; highlight `350ms` at `420ms`; total ~`950ms`.

## API

- `window.weaknessHighlightSweep.run(root)`
- `window.weaknessHighlightSweep.reset(root)`
